# Asinakech Portfolio

A responsive personal portfolio built with React and Vite. It includes an introduction, skills, projects, education, and contact links.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Build and lint

```bash
npm run build
npm run lint
```

The contact form prepares a message in the visitor's email app for `asinakechgibore@gmail.com`. Direct contact links are also provided for the two Telegram channels.
