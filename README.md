# Asinakech Portfolio

A personal portfolio website built with plain HTML, CSS, and JavaScript.

## Files

- `index.html` - Portfolio page structure and content
- `style.css` - Layout, responsive styles, and visual design
- `script.js` - Navigation, reveal animations, and contact form behavior

## Run locally

Open `index.html` directly in a browser, or start a local server:

```bash
npm start
```

Then visit `http://localhost:5500`.

The contact form opens the visitor's email app with a prepared message addressed to `asinakechgiboregibore@gmail.com`.
